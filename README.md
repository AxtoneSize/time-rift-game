# 穿越找茬（Time Rift）· 微信小游戏

> 单图找穿越物：每关一张怀旧场景，限时揪出混进来的现代物品。
> 「这些不该出现在这里的东西，你能全找出来吗？」

当前进度：**第 1 关完整实现**（第 1 章小镇夏天 · 90 年代小卖部，3 个穿越物）。

## 玩法（对照策划方案 v2.0）

- 限时 90 秒，找出图中全部 3 个穿越物（珍珠奶茶杯 / 智能手机 / 共享单车）
- 第 1 关为教学关：误点只提示不扣时
- 星级按剩余时间：≥45s 三星 / ≥20s 两星 / 通关一星
- 金币：30/20/10 + 零误点额外 +5
- 道具：提示（免费 3 个，耗尽后看广告补）· 时间归零可看广告续 30 秒 · 三星结算可看广告金币翻倍
- 时光图鉴：每揪出一个穿越物收录卡片 + 一句年代冷知识
- 广告位全部为用户主动触发的激励视频；未配置广告位时使用游戏内模拟弹层兜底

## 快速开始

### 浏览器预览版（手机/电脑均可）

纯静态零构建，直接打开 `index.html` 即可（建议本地起个静态服务，或部署到任意静态托管）。

```bash
# 任意静态服务器，例如：
npx serve .
# 或
python -m http.server 8080
```

### 微信开发者工具

1. 打开微信开发者工具 → 导入项目 → 选择本目录
2. AppID 使用测试号（`touristappid`）或替换为你的小游戏 AppID
3. 编译运行即可；真机预览前在 `project.config.json` 换成自己的 AppID

### 测试与校验

```bash
node tools/smoke_test.js        # 无头冒烟测试（40 项断言，覆盖核心循环）
node tools/validate_levels.js   # 关卡数据校验（画幅内/三区分散/热区重叠）
```

## 技术选型

原生 Canvas 2D 零引擎 + 双端同源架构（小游戏 `game.js` 与浏览器 `index.html` 共用同一份 `js/`）。详见 [docs/技术选型.md](docs/技术选型.md)。

## 工程结构

```
game.js / game.json / project.config.json   # 微信小游戏工程
index.html                                   # 浏览器预览版入口
js/                                          # 业务代码（配置/关卡数据/UI/音频/存档/广告/场景）
assets/scenes/                               # AI 生成的怀旧场景插画（已裁水印）
tools/                                       # 冒烟测试 + 关卡校验 + 图片预处理
docs/技术选型.md                              # 技术选型与架构说明
```
